### Current Documentation and Help

* [Released Grape README](https://github.com/ruby-grape/grape/blob/v{{ site.data.releases.grape.current }}/README.md): Installation, usage, and compatibility for {{ site.data.releases.grape.current }}.
* [API reference](https://www.rubydoc.info/gems/grape/{{ site.data.releases.grape.current }}): Versioned reference documentation.
* [Upgrade guide](https://github.com/ruby-grape/grape/blob/v{{ site.data.releases.grape.current }}/UPGRADING.md): Breaking changes and migration guidance for the current release.
* [RubyGems versions](https://rubygems.org/gems/grape/versions) and [Git tags](https://github.com/ruby-grape/grape/tags): Published releases, rather than the unreleased version on the default branch.
* [Grape issues](https://github.com/ruby-grape/grape/issues): Questions and bug reports. Extension-specific issues belong in that extension's repository.
* [Contributing to Grape](https://github.com/ruby-grape/grape/blob/master/CONTRIBUTING.md): How to contribute code, documentation, and fixes.

### Historical Talks and Tutorials

These resources document earlier versions of Grape and its ecosystem. They are retained for context, not as current installation, authentication, or deployment guidance.

* [Google Group archive](https://groups.google.com/group/ruby-grape): Historical community discussions.
* [Anatomy of a Ruby Gem: Grape](https://vimeo.com/98830727): A screencast digging through the internals of Grape.
* [The Grapes of Rapid](https://www.youtube.com/watch?v=C7beg3OzxC4): RubyConf 2010 presentation about Grape and [slides](https://github.com/downloads/ruby-grape/grape/The%20Grapes%20of%20Rapid.pdf).
* [API Authentication w/ Devise](http://code.dblock.org/grape-api-authentication-w-devise): A tutorial on how to use Grape with Devise/Warden authentication.
* [RESTful APIs with Grape](http://www.slideshare.net/dblockdotorg/building-restful-apis-w-grape): NYC.rb presentation about Grape in 2011.
* [From Zero to API Cache in 10 Minutes](https://www.youtube.com/watch?v=e9HLflRXMcA): a 10-minute talk at GoRuCo 2012 about API caching with Grape.
* [OAuth2: Protect Grape API with Doorkeeper](http://blog.yorkxin.org/posts/2013/11/05/oauth2-tutorial-grape-api-doorkeeper-en): a tutorial for protecting a Grape API with OAuth 2 protocol using Doorkeeper and Ruby on Rails with a [working sample](https://github.com/chitsaou/oauth2-api-sample).
* [API Heaven with Grape and Swagger](http://bitboxer.de/2014/02/09/rails-api/).
